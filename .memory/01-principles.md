# 设计原则与代码规范

- Python + PyQt6；高内聚、低耦合，不过度防御性编程。
- 分离结构模型、文件读写、编辑操作、三维渲染与 Qt 界面；领域层不得依赖 Qt。
- 内部采用 Direct 分数坐标；晶格矢量按行存储，笛卡尔坐标单位为 Å。
- Python 使用 snake_case、类型标注和清晰命名；仅对外部输入及模块边界做必要校验。
- 不吞异常；用户可操作错误显示在界面，详细异常写日志。
- 默认配置纳入版本控制，用户配置覆盖默认配置；禁止修改默认配置保存用户偏好。
- 结构编辑后续采用命令模式支持撤销/重做；文件保存避免破坏原文件。
- 新增复杂依赖和界面风格须有明确理由；避免提前抽象。

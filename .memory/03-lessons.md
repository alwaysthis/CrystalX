# 经验教训

- 旧项目分数坐标为内部真值，切换显示坐标系不应改变结构。
- MATLAB 方法清单只是迁移参考，不能当作 Python 已实现功能。
- 无终端启动必须将启动失败写日志并提供可见提示。

- Qt offscreen 截图环境需显式加载 Windows 字体，避免中文显示为方框；不应误判为正常窗口字体缺失。
- 2026-10-31：已安装虚拟环境依赖，check_ui.py 离屏检查通过（坐标表展开、重置视角、截图生成）。

- 2026-11-01：原子数量改变后必须清空旧索引选择；快照命令在副本上执行，失败时不污染当前结构。旋转必须明确轴、中心和坐标系，倾斜晶格下需先转笛卡尔坐标。

- 坐标参考系切换共用一张表，只更新数值，避免两张表滚动同步漂移；刷新保留滚动和原子展开状态。图标使用本地 SVG 渲染，避免 Unicode 符号缺字。

- 透明坐标标签覆盖在有文字的 QTreeWidgetItem 上会出现双重文本；底层单元格必须清空。高分辨率图标应渲染完整 SVG 到大像素画布，避免 devicePixelRatio 与 renderer 逻辑尺寸不一致导致裁剪。周期镜像必须保存源原子编号映射。

- 用户所指标题栏为窗口最上方，不能用菜单下工具栏替代；自定义标题栏须保留窗口控制、系统拖动、双击最大化及缩放入口。

- 自定义标题栏窗口按钮不依赖 QStyle 系统图标；使用内置 SVG，监听 WindowStateChange 同步最大化/还原图标，避免不同系统主题缺图。

- 预设视角后的拖动必须在当前相机矩阵上叠加屏幕空间旋转；不能清空矩阵回退到旧 yaw/pitch，否则第一帧会跳变。七种预设及倾斜晶格都需验证零位移连续性和小角度增量。

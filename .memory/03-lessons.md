# 经验教训

- 居中工具栏不能只在水平布局两边addStretch，两侧固有宽度不等会偏移；按容器几何中心定位，窄窗另行排布避免覆盖。
- 高度分布的均值/方差须按像素频数加权，不能对分箱横坐标直接求平均；结果是分布近似，不等同于从原始二维图进行平面校正后算粗糙度。
- 框选寻峰先裁剪X再检测，最后按原始Y过滤；需保存完整源索引映射，避免把局部数组索引用于原图标记。范围改变且计算失败时清除旧结果表，防止旧结果与新范围混淆。

- 寻峰要与显示变换分开，不能因图为对数轴就对log强度当作原始信号检测；SciPy峰宽是相对突出度的宽度，不自动等于物理拟合FWHM。
- SciPy的distance/width按采样点定义，物理角度约束和非等距扫描应转换实际交点/距离；降序输入还要映回源点索引，不能把排序索引直接用于标记原曲线。
- 自动阈值是启发式，强弱峰动态范围大时需允许手动调小；自动峰标记与手工标点分别管理，清除分析结果不能误删手工标注。

- AFM文件名出现Height不代表二维形貌矩阵；先核对单位头和列语义。高度(nm)—Pixel两列是频数分布，应画高度/像素数曲线，不能臆造空间坐标或二维图。
- 扩展现有科学曲线绘制时，把标签和来源放进共用Qt无关模型，保持XRD旧入口兼容；避免在AFM页硬编码Intensity、2θ或直接继承用户XRR对数默认。

- 对数变换正确不代表刻度外观完整；强制禁用minor locator会抹掉经典对数数量级内的疏密变化。主/次定位器与格式器分别设置，次标签留空，明确保留显式数组的精确语义。
- 核验内置模板默认值时直接读default文件；自动解析会优先读用户custom，不能把用户正常修改误判为默认配置回归，也不能为测试清理用户配置。

- QMenu中同时设置icon和checked可能让图标占据状态列，导致勾选不见；明确需要方框的选项去掉前置图标，统一QMenu::indicator样式，排他选择用QActionGroup。用真实菜单截图核验，而非只断言isChecked。
- 上标科学计数的存储字符串可以含数学源码^，应验证排版后的glyph大小/基线，不应把源码字符检查当作实际显示效果检查。

- 图例文字命中应按实际可见条目到源曲线索引的映射，不能按文字名称查找或直接把可见行号作为源索引；隐藏曲线和同名曲线都可能让这两种映射失效。

- 移除样式中的范围控件后，旧样式草稿仍可能含过时范围，应用时应从当前图取范围；主数据轴缩放也要同步显式限值，否则刻度装饰轴会停在旧位置。
- 设定整图比例时让绘图组件置于居中宿主中，保持鼠标事件/拾取/图例拖动坐标统一；导出只取Figure，从而不带宿主留白。测试需比较同一父坐标系中的控件位置，不能直接比较不同父对象的geometry。
- “应用于模板”要区分自带默认和用户文件，自带修改写custom同名覆盖；通过临时配置根验证，不让自动测试改用户默认模板。

- 新增非线性轴要同时修改主数据轴、四边装饰轴、刻度定位、范围校验与鼠标缩放/平移，不能只改变标签格式；刻度数组仍输入原值，指定间距则明确在哪个变换空间定义。
- PyQt6的QColorDialog没有standardColorCount；设置标准色使用已有setStandardColor，不能把相似API名当成实际可调用方法，必须运行颜色窗口验证。

- XRD和XRR可能同为TwoThetaOmega，不能仅凭扫描轴或文件名断言类型；先读测量类型，缺失时以低角范围推断并保留手动模板选择。实际样本识别通过不等于对所有测量无歧义。
- 图内容与样式分开：模板不应覆盖用户改过的轴标签文字；双击内容编辑时，也要同步已打开的样式草稿，避免后续应用恢复旧文字。
- Qt截获了Canvas事件就不能依赖Matplotlib自带拖动回调；需显式在图例命中时进入独立拖动状态，避免平移数据。位置使用轴归一化坐标，在Figure替换后恢复。

- 右键QContextMenuEvent.pos()返回QPoint，普通鼠标position()返回QPointF；PyQt的QRectF.contains不会隐式转换QPoint。菜单构造测试不能代替实际事件分发，需发送真实上下文事件并核验Qt回调没有未处理异常；pythonw没有终端时这类异常可能直接退出且不进入包围app.exec的try/except。

- 旧项目分数坐标为内部真值，切换显示坐标系不应改变结构。
- MATLAB 方法清单只是迁移参考，不能当作 Python 已实现功能。
- 无终端启动必须将启动失败写日志并提供可见提示。

- Qt offscreen 截图环境需显式加载 Windows 字体，避免中文显示为方框；不应误判为正常窗口字体缺失。

- 预设视角后的拖动必须在当前相机矩阵上叠加屏幕空间旋转；不能清空矩阵回退到旧 yaw/pitch，否则第一帧会跳变。七种预设及倾斜晶格都需验证零位移连续性和小角度增量。

- QToolButton 不能继承按钮的大水平 padding，否则 SVG 图标被挤缩；图标应保留独立内边距。原子标签空单元格不是结构选择控件，列表禁用单元格选择。CIF 导入不能把不对称单元当完整晶胞；展开对称性后再转模型。

- 离屏渲染大量镜像原子时，固定等待双击间隔后立即断言存在调度波动；使用有上限的条件等待验证单击清空结果。2026-11-14：10 项领域测试和界面联动（透视、滚轮保护、标题栏、选择）通过。

- 原子色表相同不等于渲染相同；径向渐变与透明叠加不能复现球面光照，深度淡化应用背景雾色，避免看到球体内部线条。无边框透明弹窗必须主动绘制圆角背景和外框，不能只设 stylesheet。

- 用户明确禁止用遮罩实现弹窗圆角。此前 setMask(QRegion(...)) 会产生锯齿缺角；必须彻底删除，透明底色和外框都在完整窗口内抗锯齿绘制。页面圆角需连同内容层实现，不能只画 tab 顶角。文件/目录选择器必须保留系统原生行为。

- 球体光照材质不能将相机深度/雾化作为 Python 像素生成缓存键：每次旋转会触发大量昂贵重建。缓存按元素 RGB 分离；光照样本共享，雾化用 Qt SourceAtop 原生合成并限量缓存，图像用 premultiplied ARGB。每帧原子相机变换只算一次供投影/半径/排序复用。

- 多文档不能只在标签切换时替换全局结构：结构、撤销历史、相机和 UI 编辑状态必须分别归属于每个 StructurePage；关闭/重排按 widget 身份寻址，不能捕获旧标签索引。终端输出共用主窗口，关闭结构前处理未保存状态。

- 给标签面板增加外框后，隐藏与最大化必须操作包裹容器；只隐藏标签控件会留下占空间的空框。标题栏边线须在子控件几何范围外预留独立像素。

- 标题菜单容器不能使用无选择器的 background:transparent；会优先覆盖其 QMenu 子窗口背景，alpha=0 导致系统上呈黑色。容器 QSS 必须以 objectName 限定，弹出菜单使用独立 MENU_STYLE 与浅色 palette。

- 只有贴边浅色 QSS 边框不足以表现独立面板。外部间距、真实圆角底板、内缩内容与上层轮廓应成套实现，且用左右边线像素和截图核验，不仅检查样式字符串。

- QMainWindow 的内部布局会自行管理标题/中心区域，给 layout 设置 margins 不保证内容内缩；透明圆角主窗应调用窗口自身 setContentsMargins，并用实际截图确认边框未穿过子控件。
- VESTA 矩阵以列表示新基矢，而本项目晶格按行存储，因此要转置后左乘；变换晶格时先保存旧笛卡尔位置，再反算新分数坐标。参数编辑和基变换必须分别测试两种坐标不变量及撤销。
- 编辑表格刷新须比较结构快照，单纯视口选择变化不能覆盖未提交的单元格或联动表格行选择。独立选择不应依赖阻塞几次信号，应取消跨组件选择连接。

- QTabWidget 的 QTabBar 默认宽度只到最后标签，给它加背景不能改变整条空余区域；需在父标签窗口绘制完整顶条背景。
- 周期成键必须考虑同源原子不同周期像、倾斜晶格所需的邻胞范围及边界键段去重；不能仅对当前可见原子两两求距离。键搜索与相机绘制要分开缓存，端点变换要复用，避免每根键重复计算两个原子的变换及半径。
- 晶格编辑预览使用副本、失焦从原结构和当前全部输入重建；不能每次失焦累积矩阵。只有应用才提交命令，关闭恢复已提交结构。

- 用户要求搜索范围参照VESTA时，应读取其实际默认元素对表，不能用共价半径倍率代替。表内同一无序元素对可能有多条距离区间，不能仅用最大值归并；未列元素对默认不搜索。
- 父标签条改圆角仍可能被子QTabBar的矩形填充盖住，必须同时去掉子控件背景填充。网格标签被拉宽导致标签和数值框分离时，应只给数值列分配stretch。

- 显示样式和键定义是不同入口：前者只负责渲染外观，后者负责元素对与搜索范围。修改配色、宽度等不得顺带提交另一个窗口中的搜索草稿；多文档弹窗必须跟随所属页隐藏和关闭。

- 标签条要求触边时，不能只扩大深色绘制区域而保留容器原有5px边距；应将工作区容器对应边距收至1px，同时同步内外圆角并保留上层边框。

- 重置朝向不能使用固定世界方向(1,1,1)再投影c来冒充晶格相对标准视角；应从实际晶格建立正交相机。Fit to screen还需包含球体半径，固定zoom=1不能保证宽长结构或不同视口大小不裁切。
- 标签与面板要求相同圆角时，应共享一个半径常量、同时应用于左右角；圆弧与二次贝塞尔拐角即使边界尺寸一致，轮廓仍有差异。

- 非最大化菜单高亮不触顶时，应区分阴影区9px和原内容边距15px导致的6px实色留白；只修改按钮高度不能消除留白。标题高度、按钮高度和窗口顶部边距需要一起调整。

- 隐藏是显示状态，不应删除模型原子；必须以源原子编号过滤周期镜像、标签、拾取和关联键。混合可见性状态不能用普通二态动作表示。
- 表格新增删除后不能按新行号复用旧原子的flags；草稿行应携带源原子索引，新增行用None，以保留源标志并明确拓扑变化。
- 键规则表删除/清除后，应用必须清空先前编辑过的元素对，否则从原范围字典复制会让已删规则重新出现。
- 晶格变化预览需共用世界尺度并绘出参数中间态；矩阵输入属于科学数据边界，整数与非奇异约束必须在不依赖Qt的领域模块校验。点阵显示不能无界枚举巨大整数晶胞，按密度抽样且仍保持整数格点。

- 键表“有site才显示”必须判断实际距离匹配，不能只看结构里是否同时存在两种元素。跨周期边界的键段会被裁短，规则匹配要用原始完整距离；多个区间即使产生相同几何键，也应分别记录匹配。
- 过滤未匹配规则仅影响行可见性，不能把隐藏行当已删除；新建/修改草稿应在应用后才筛选，避免编辑过程或点击视口时行突然消失。

- 三种显示作用范围不能只换一个下拉框：需要真实的源原子/键段/晶胞边局部覆盖，以及打开/未来文档共用的会话全局基线；加载/保存默认与当前结构数据应解耦。
- 材质参数必须参与实际绘制与缓存键，粗糙度和折射率不能只存于表单。材质光照仍缓存，视角雾化保持Qt原生合成，避免回归每帧像素重建。
- 恢复默认应读用户已保存的全局默认，设为默认写custom而非default；预设加载必须校验完整字段和数值，导出与对象覆盖分开，避免把结构数据意外写入显示预设。
- 全局设置若随后被每个新页面的旧config键覆盖，会导致新结构不继承；旧配置只在会话初始化时合并，页面创建只读取当前全局基线。

- QDialog中的QPushButton默认autoDefault可能让第一个颜色色块成为Enter目标；只处理键盘事件会漏掉焦点切换，应在色块和辅助按钮上关闭自动默认，输入框Enter只提交编辑。
- 给Qt内建颜色窗口安装自绘外框不足以统一内部UI：需要处理其内部标签/按钮翻译、控件样式及私有绘制色条。明度条旁的白带来自QPainter.eraseRect，不是普通控件背景；只改palette和QSS不能解决。
- 测试十六进制编辑时用真实按键触发textEdited；程序setText只触发textChanged，不等于用户输入，不能据此误判Qt颜色值未更新。

- “直接编辑当前颜色/半径”不需要用户先切换自定义模式；显示有效默认值，用户输入后在内部建立覆盖即可。默认表必须只读；尤其注意UI名义半径与原有球棍显示缩放的换算，避免从默认值直接修改时尺寸跳变。
- 证明粗糙度/IOR有效不能仅检查字段保存，要检查渲染像素和高光宽度/强度。Blinn指数与经验高光系数不等同于Blender Principled；参考其定义可用GGX/Smith+Fresnel，但应明确单光源投影渲染的边界。
- 材质系数在像素循环内反复计算会抬高首次显示成本，应按roughness/IOR/gloss预计算并缓存，旋转帧继续复用材质图像。

- 连续光泽不能仅把布尔开关换成数值框：需要让实际BRDF按强度缩放、验证中间值像素变化，并迁移旧布尔预设以保留外观。

- 性能评估须分清内核冷调用、缓存命中、结构刷新与实际绘制；cProfile单独运行。C++收益应包含调用边界和图像复制，以交替采样与像素一致性确认；不把球体单内核加速倍数外推为整个界面加速。

- 原生迁移不要自行用std::round替换Python round(v,8)做几何去重，二者半值语义不同；保留Python后处理可稳定键段编号。周期坐标%1对极小负数可能为1.0，不能在C++边界按严格小于1拒绝。
- Python参考基准脚本在原生接入后需显式禁用扩展/调用参考函数，避免把已经加速的调用误标成Python基线。原生构建与缺失回退均需独立核验，不依赖原生专用测试被跳过后的“通过”。

- 多类型文档不能假设每个标签页都有结构document/viewport/编辑弹窗，需同步核验全局显示应用、菜单、关闭及切换。XRD图只画原始强度，不能未说明就使用衰减列修正；没有实际样例时区分合成验证与真实文件核验。

- 离屏检查创建多个顶层Qt窗口时，结束前显式deleteLater并派发DeferredDelete，避免仅关闭窗口后依赖Python/Qt销毁顺序造成退出访问冲突。

- 透明科学图不能用widget.grab得到：共享纯绘图函数，在透明ARGB画布上只画坐标/标签/数据；屏幕白底独立处理。图框内外都要测alpha，确认悬停工具栏不会进入导出。指数用正常数字小字体排版比Unicode上标更可靠。

- 论文绘图需要字体、数学排版、刻度定位、图例及矢量输出时，应统一到标准绘图后端；不能继续堆QPainter文本近似。log默认clip会把0连接到极低值形成伪线，要用mask断点。
- Qt空QStackedWidget的布尔值可能为False，选择目标容器必须使用is not None，不能用stack or fallback。通用继承与样式对图的实际作用需在界面测试，而不只比较设置字典。
- MATLAB风格标签不足应补空白，数字可转文本，不能因标签数量不相等直接报错。兼容字面量并不等同于完整MATLAB执行环境，须明确语法边界。Mathtext与完整LaTeX也需区分。

- 绘图边距不能只在固定百分比基础上向内收缩，要按标签实际装饰尺寸计算可回收的空间；QtAgg换Figure不等于换Canvas，已有device pixel ratio不会自动重新应用到新Figure，需同步DPI并分别测试100%/150%/200%。

- 跨图复制曲线时应把源图继承的颜色/线宽转成曲线显式值，否则目标图通用样式会改变粘贴外观；复制数据与图级预设要分开，预设不得意外写入研究数据。
- 多曲线不能继续用单一curve样式字段覆盖所有线；分别维护曲线草稿，轴菜单切换log等图级操作不应把旧curve字段覆盖到当前选择。
- 自动标签需区分None与空字符串，编辑器显示有效名称而不是空字段；用户主动清空时应允许隐藏。
- 配置加载中的字段路径循环不要复用文件路径变量，后续目录记忆会拿到元组而非文件；用真实MainWindow/SessionState测试配置成功加载后的目录持久化。
- 字体下拉显示字体名称即可，不按各字体自身渲染整行，避免超大预览和异常行高；选择高亮用Qt叠层，保证导出图片不混入编辑辅助效果。


## 0.29.0 数学UI与粘贴规则修订

- 最新要求以美元分隔符显式启用数学语法；不要自动把文件名、标签、普通上下标源码当公式。编辑/复制保持原字符串，预览单独绘制。数学排版使用Mathtext子集，不能声称完整外部LaTeX引擎。
- 跨图曲线最新语义是融入目标图，覆盖此前“物化源通用颜色/线宽”经验；保持图例内容与线型/标点，颜色和线宽回到目标继承，图例同步重建。
- 扩展Qt组件前核对子类是否有同名属性（HelpButton.text），以及findChildren类型判断是否仍需原生Qt基类；异常发生在paintEvent时可能导致整个进程退出，交互检查安装异常钩子并验证常用弹窗。
- 批量打开在每项成功后更新目录，错误末尾汇总；不要只记录最后一个选择路径，因为它可能失败。

- 曲线选中提示不能用固定颜色整线覆盖，否则实际样式和图例虽已同步，屏幕仍看似旧色/错色。用稀疏空心圈保留真实笔画，并验证选中状态下的屏幕像素；仅断言artist.get_color不足以发现此问题。

- QTextDocument.adjustSize会让长的混排文字隐式换行；单行公式控件需显式NoWrap，否则按高度缩放的预览会变成多行小字。换行策略要随控件语义设置，而不是对所有标签强制不换行。


## 0.30.0 背景与宽度

- 半突出度宽度不是一般意义的FWHM；保留两列并定义局部扣底/半高交点插值，重叠峰不宣称已精确拟合。
- 背景扣除必须保留原数据，通过display_y统一屏幕、拾取、标点、寻峰和导出；修改样式不能用旧字段列表重建PlotCurve而丢失新增处理状态，使用dataclasses.replace。
- AsLS在等x间距工作，非等距先均匀重采样；平滑参数按采样数四次方缩放。自然端点可有小偏差，扣底可能产生负值，禁止截零伪造数据；log只mask显示。
- 新功能回归测试不要默认用户custom模板是线性或未修改的默认配置；检查自带模板直接读default，集成测试尊重用户覆盖但不写回。


## 0.31.0 强动态范围与Qt回调

- 只用温和高斯合成数据证明不了百万计数XRD的背景质量；同时验证真实强峰、零计数噪声、峰尾与模型负值，并对比量化。线性AsLS的平方损失会受强峰牵引，强动态范围需变换/削峰或其他稳健方法。
- 直接对含大量零的计数做SNIP会把背景压至零；先在计数域做可调预平滑，再LLS削峰。模型非负约束与裁切扣底数据不同，后者禁止。SNIP窗口不足会把宽峰尾误作背景，必须可调。
- Qt窗口成员不要叫width/height/text等已有可调用接口名；BackgroundDialog的数值控件最初覆盖width()触发chrome回调TypeError，已改window_width。真实显示/缩放与异常钩子检查应在交付前执行。
- “峰轮廓”应清楚说明是检测区间轮廓，不能未经拟合就造高斯曲线；平滑叠加仅画峰附近，避免在对数图全背景铺满噪声。实际计算用的信号与显示必须一致。
- 独立显示开关不能混用结果生命周期；隐藏背景线不改变信号，不清峰；改变扣底信号则应使旧结果失效。分析元数据不写样式模板，曲线复制时可携带并校验。

- 公式委托选中态不能盲取系统HighlightedText：QSS浅色背景可能仍配系统白字，需成对管理背景/前景。QComboBox popup使用独立委托统一普通文字和公式，实际弹出截图验证。
- 小尺寸圆角QSS虚线沿闭合路径的相位会导致角部/左右边不对称；以对称圆弧和等距直边分段绘制，并在多个DPI比较镜像像素，避免只检查样式声明。


## 0.32.0 拟合与平滑的区别

- 局部SG平滑即使连线很密仍会跟随噪声，不能称作峰型拟合；用户要光滑峰型时应拟合观测到受约束模型，并让峰位/FWHM/标记来自同一组参数。
- 宽峰顶噪声的局部极值不能直接当分峰；相对突出度+有限分辨率筛选，BIC仅用于接近候选的复杂度比较，同时验证真双峰不会被盲目合并。
- 支持区间按左端排序合并再按中心排列组内种子，避免宽峰桥接时分组重叠、密集模型曲线倒序或被截断。
- 拟合密集点可多于源采样点，剪贴板校验应区分源点索引和模型评估网格；原始强度与连续模型中心/模型强度要分别存储，不能用最近噪声源点代替模型标记。
- 用数据自身强度作权重会在温和计数噪声下压低峰顶；实际宽峰检查后改按动态范围选噪声缩放/计数权重，报告模型局限，不只追求曲线看上去光滑。


## 0.33.0 XRR膜厚

- θ/2θ、波长Å/nm、qz单位必须显式转换；少一个2或10会得到成倍错误厚度。按qz差拟合比小角度直接差更清晰，临界边须排除或显式修正。
- 连续编号与漏峰级次必须可区分；剔除噪声峰通常重编号，跳过真实漏峰则保留间隔。两峰R²=1没有诊断意义，回归标准误也不是包含系统误差的总不确定度。
- XRR尾部噪声异方差，不宜全范围统一噪声阈值；自动条纹须局部筛选并让用户核对，不能把近似等距噪声序列当物理膜厚证明。
- 工具栏换行会在Qt布局中产生暂时1px画布，跳过小尺寸绘图并在真实resize后刷新；不能让异常出Qt回调导致闪退。截图前派发待处理布局事件，避免把尚未展开的结果标签当最终显示。


## 0.34.0 崩溃诊断与独立标记

- app.exec外层try捕获不了Qt回调异常；pythonw无控制台时可能只看到0xc0000409和启动日志。必须记录sys.excepthook、线程异常和native堆栈，保留关键操作上下文，并区分历史猜测与实际复现。
- 原生QMessageBox改变flags/style后可删除重建布局；安装主题外框时在变更后重新取layout，不能沿用调用前保存的QGridLayout。错误报告窗自身也要用真实回调注入验证，否则新的报错器可能再次报错。
- 分析标记分来源存储；膜厚开关不得覆盖手工点或自动峰。使用统一Figure绘制以同步导出，级次/峰位属于数据分析状态，不写样式模板。

## 0.35.0 可编辑绘图文档与曲线身份

- QApplication事件过滤器收到的不止QWidget；QWindow同样接收ContextMenu。调用widget.window()前必须确认类型；右键日志不能成为界面操作的失败原因。
- QPainter归属应在异常路径也保证释放，尤其数学绘制可能因输入错误抛出；with QPainter消除等待垃圾回收导致的活动画笔警告。
- 派生模型要可编辑、可删除和有图例时，必须升级成正常曲线，不能只在Figure画一条无数据身份的叠加。图例隐藏与曲线隐藏分别管理，命中图例时必须使用筛选后的原曲线索引。
- 删除/撤销会改变曲线索引；关闭旧分析和内容编辑窗口，或按稳定uid定位，避免非模态窗口继续引用错行。跨图粘贴创建新uid，复制文件信息但不继承源图父子依赖。
- 图文件保存和样式模板用途不同：前者包含原始/分析数据、视图，后者包含样式及当前要求保留的轴文字。None与显式空字符串不能混用；轴标签不生效曾是模板写入主动清除label造成。
- 文档中的活动扫描必须用身份定位；list.index使用值相等，两个同样数据的扫描会错误保存为第一个。读写回环同时比较未修改空处理设置，避免校验默认值扩展使恢复状态无故变化。
- 数学表达式输入只解析允许的语法树，不eval；Mathematica风格输入子集需说明边界，不能声称支持完整语言。原始表达式存档只是元数据，打开图文件不执行它。

## 0.35.1 低计数曲线不能机械套用强信号门槛

- 单点噪声与平滑种子的噪声不是同一水平；固定数点平滑加原始5sigma阈值可能只留下噪声尖峰，遗漏跨数百点的弱宽峰。识别初值可平滑，模型拟合仍须使用原始观测。
- 原始R²同时受计数噪声和信号幅度影响。不能简单把低于0.65的宽峰全部判失败，也不能用平滑后的高R²替代原始R²。需额外检验趋势/基线模型改善、拒绝纯噪声并保留低信噪比提示。
- 宽尺度重试只用于原流程失败或无结果，保持已验证强峰/双峰行为；宽峰初值并不等于可以分辨亚分辨率双峰，不宣称参数唯一性。

## 0.36.0 原始单位与分析单位

- 角度/计数单位转换必须同时覆盖曲线数组、分析输入、拾取、默认标签、保存及旧文档迁移；只改标签会产生量纲错误。XRR转q后膜厚窗口必须同步选q输入。
- 保留原始扫描和单位明确的绘图曲线两层；转换后的metadata参与幂等判定，避免重开.cxplot再乘计数率因子。模板默认轴文字读绘图副本，文件信息同时区分原始与绘图坐标。
- RASX的RASHeader只含部分附加键，不能以为它等于RAS文本完整头部；结构化ScanInformation才有单位、步长和速度。测试中必须用不含RASHeader的结构化样本覆盖此路径。

- 全部图例条目隐藏不能删除交互容器，否则右键恢复入口同时消失。将空Legend作为锚点保留，编辑占位/悬停反馈在Qt层绘制，避免导出空框或手柄；重新启用条目沿用同一位置。

- 同一AFM外观模板可以服务不同数据语义；线剖面Y是带符号高度，Region的Y是非负像素频数。识别长度-长度与长度-pixels后分别生成轴标签和统计，不能因模板相同而套用同一套权重计算。

- 图片比例拖动使用全局鼠标位置与初始尺寸计算，避免手柄随重排移动造成反馈跳动；连续拖动节流并合并成一次历史。手柄作为host子控件隔离于科学图导出，比例改变不重置数据范围。

## 0.37.0 条纹相位与原始峰顶不能混淆

- 去趋势残差的极大值不必是原始反射曲线的极大值；标注原始峰顶前需回查，不能把下降斜坡上的相位候选画成已确定峰。
- 以裁剪后样本数设滤波尺度，会使同一曲线改变分析范围就出现更多伪峰；应在完整数据上建立物理尺度，再过滤输出，测试裁剪是子集关系及降采样稳定。
- FFT零填充只是频谱插值，不提高真正分辨率；多周期或疑似漏峰不可强制补齐等间距点。状态需进入可视化、表格、CSV和膜厚勾选逻辑，而不只在计算内核打分。
- 原始数据含零时，丢弃零再取log会低估尾部噪声；可对有效正值插值用于识别，但必须保留零计数比例来降低可信度，且不可改写原始数组。

- 自绘QTabBar与系统原生关闭按钮混搭时，系统选中态图标颜色和几何可能不匹配。统一按钮绘制和实时索引映射，实际检查选中/未选中图标像素、滚动溢出及最后一页关闭，不能仅验证close_tab函数返回值。
